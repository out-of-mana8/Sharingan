# Sharingan

Sharingan is an ESP32-P4 camera/display board built around the Waveshare ESP32-P4-Module.

## Repository contents

- [`docs/DESIGN_REVIEW.md`](docs/DESIGN_REVIEW.md) — schematic and netlist engineering review dated 2026-08-30.
- [`design/ESP32P4_Camera_Board_Schematic_2026-08-30.pdf`](design/ESP32P4_Camera_Board_Schematic_2026-08-30.pdf) — source schematic PDF reviewed.
- [`design/Netlist_PCB1_2026-08-30.tel`](design/Netlist_PCB1_2026-08-30.tel) — source EasyEDA TEL netlist reviewed.
- `drawing.pdf` — existing board drawing.
- `top 2D.png`, `Top 3D.png`, and `top layer.png` — existing board views.

## Current status

The schematic and netlist review is complete. The design is not yet recommended for fabrication; see the stop-before-fabrication findings in the review.

A complete PCB review still requires the editable PCB source or Gerbers, layer stackup, design-rule settings, and fabrication/assembly outputs.
